## Primary implementation research and acceptance

No additional packages are needed for the implemented custom marks or local example owners. These official sources informed the implementation directions:

- [Editor decoration example](https://codemirror.net/examples/decoration/) and [system guide](https://codemirror.net/docs/guide/): map decoration ranges through document changes; further layout-changing folds and multiple selections need deliberate state ownership.
- [Web-component virtualizer source](https://github.com/lit/lit/tree/main/packages/labs/virtualizer): separate logical records from realized nodes and update bounded windows.
- [Custom-series tutorial](https://apache.googlesource.com/echarts-doc/%2B/refs/heads/master/en/tutorial/custom-series.md): function-based marks can map coordinates and clip without another dependency; this approach is now implemented for two chart examples.

Acceptance still requires readable, compact rendering in both themes; narrow and expanded/zoomed previews; retained state across composition; real user-visible outcomes; keyboard behavior; and direct comparison of all relevant visual treatments. Automated overflow and registered-element counts remain guards, not a substitute for that review. Stories do not close outstanding component parity.
